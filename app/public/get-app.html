Sign in here first

Before you install the app, sign in on this website once. The phone app does not set up new accounts — it only signs in accounts that already exist. If you install it first, it will tell you the account is not set up yet, and this is why.

If you have already used Kanban in a browser, you are done; go ahead and install.

Android

Google Play Open on your phone, tap Accept, then install from Google Play. Use the Google account an administrator added as a tester; if Play says the app is not available, ask an administrator to add you.
